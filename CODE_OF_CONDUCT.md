# Code of Conduct

Be respectful. Criticism is welcome; harassment, personal attacks,
discrimination, threats and sharing private information without consent
are not.

These rules apply to project discussions, issues, pull requests and
other spaces where someone represents the project.

Maintainers are responsible for handling reports and may remove content
or restrict participation when necessary.

To report unacceptable behavior, contact:
